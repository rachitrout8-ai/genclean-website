# GenClean website

A free, static, responsive website concept for a college entrepreneurship project.

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, e.g. `genclean-website`.
3. Upload `index.html` to the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site. The URL will look like:
   `https://YOUR-USERNAME.github.io/genclean-website/`

## Important project notes
- GenClean is presented as a proposed student startup concept.
- Package prices are illustrative, not market-verified quotations.
- Contact email is a placeholder (`hello@genclean.example`).
- The enquiry form opens a pre-filled email draft; it does not store submissions or send them automatically.
- Replace placeholder contact details before any real-world use.
